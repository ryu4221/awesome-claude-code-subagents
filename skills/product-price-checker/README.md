# 写真で価格チェック (product-price-checker)

商品の写真を Claude に送るだけで、次の内容を調べて表にまとめる Claude スキルです。

- 商品名・ブランド・品番(型番)・JANコード
- Amazon・メルカリ・楽天市場・Yahoo!ショッピング・ラクマ・PayPayフリマ・Yahoo!オークション・価格.com での販売価格
- 価格が載っている販売ページのURL
- 新品の最安値と中古の相場
- 各サイトの最新価格を見るための検索リンク

API キーやサーバーは不要です。claude.ai のアカウントの中だけで使えます。

## 使えるようにする手順 (claude.ai)

1. `product-price-checker.skill` ファイルを用意します (このフォルダを zip にしたものでも可)。
2. claude.ai で **設定 → 機能 (Capabilities)** を開き、**コード実行とファイル作成** と **ウェブ検索** をオンにします。
3. 同じ画面の **スキル** から「スキルをアップロード」を選んで、ファイルをアップロードします。
4. スキル一覧で `product-price-checker` がオンになっていることを確認します。

Claude Code で使う場合は、このフォルダを `~/.claude/skills/product-price-checker/` にコピーしてください。

## 使い方

新しいチャットで商品の写真を添付して、たとえば次のように送ります。

- 「これいくらで売ってる？」
- 「メルカリでいくらくらいで売れる？」
- 「この商品の品番と最安値を調べて」

正面に加えて、品番タグ・箱・バーコードの写真も送ると精度が上がります。
商品が特定できないときや、容量・サイズ違いで価格が大きく変わるときは、Claude から確認の質問が来ます。

## 注意

- 価格は調べた時点のものです。最新の価格・在庫・送料はリンク先で確認してください。
- メルカリなど一部のサイトはページの中身を取得できないことがあります。そのときは検索リンクで案内されます。
