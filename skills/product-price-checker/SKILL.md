# 写真で価格チェック

ユーザーの写真に写った商品が何かを特定し、日本の主要ECサイト・フリマサイトでの販売価格を調べて、
**商品名・品番・価格・URL** がひと目で分かる形で返すスキル。

ユーザーがこの結果を使ってやりたいことは主に「買うならどこが安いか知りたい」「売るならいくらが相場か知りたい」の2つ。
どちらの場合も、価格が本当にその商品のものか、そのURLを開けば実際にその価格が載っているかが一番大事になる。
だから推測の価格やそれらしいURLを作ることは、空欄にするよりずっと悪い。確認できたものだけを書くこと。

## 手順

### 1. 写真から商品を特定する

写真に写っている文字情報を最優先で読む。ロゴ、タグ、ラベル、箱、刻印、品質表示、バーコード下の数字など。
デザインだけで判断すると似た別モデルと取り違えやすいので、文字で裏付けが取れるかどうかで確信度を決める。

特定する項目:

| 項目 | 内容 |
|---|---|
| 商品名 | 日本のECサイトで一般的な表記(カタカナ・日本語) |
| ブランド・メーカー | |
| 品番・型番 | 写真に写っている、または文字情報から確実に言える場合だけ書く。分からなければ「不明」とする |
| JANコード | バーコードの数字が読めた場合だけ |
| 特徴 | 色・サイズ・容量・付属品・状態(新品/使用感あり)など、価格に影響するもの |
| 確信度 | 高 / 中 / 低 |

品番が写真から読めないときは、Web検索で商品名から品番を調べてよい(その場合は「検索で特定」と明記する)。

### 2. 分からないときはユーザーに聞く

次のような場合は、価格調査に進む前にユーザーに確認する。間違った商品の価格を一生懸命調べても役に立たないため。

- 写真から商品が判別できない、または候補が複数あって絞れない(確信度が低い)
- 価格が大きく変わる違いが写真から分からない(例: 容量 128GB/256GB、サイズ、限定版かどうか、セット内容)
- 売りたいのか買いたいのか分からず、それで見るべき価格(中古相場か新品最安値か)が変わる場合

聞き方の例:「品番が写っていないため、候補が2つあります。A(○○)とB(○○)のどちらですか？タグや箱の品番が写った写真があれば、もっと正確に調べられます。」

確信度が中程度で、候補が1つに絞れているなら、確認せずに調べてから「この商品として調べました。違う場合は教えてください」と添えればよい。毎回確認するとユーザーの手間になるので、結果が大きく変わる場合だけ聞く。

### 3. 各サイトの価格を調べる

Web検索(と、使える場合はページの取得)で調べる。検索語は「品番」が一番正確で、品番がなければ「ブランド + 商品名 + 特徴」を使う。

調べるサイトと検索のコツ:

| サイト | 種別 | 検索語の例 |
|---|---|---|
| Amazon.co.jp | 新品中心 | `{品番} amazon.co.jp` |
| 楽天市場 | 新品中心 | `{品番} 楽天市場` |
| Yahoo!ショッピング | 新品中心 | `{品番} Yahoo!ショッピング` |
| 価格.com | 新品最安値の比較 | `{品番} 価格.com` |
| メルカリ | 中古・フリマ | `{品番} メルカリ` |
| ラクマ | 中古・フリマ | `{品番} ラクマ` |
| PayPayフリマ | 中古・フリマ | `{品番} PayPayフリマ` |
| Yahoo!オークション | 中古・落札相場 | `{品番} ヤフオク 落札` |

守ること(理由も添えて):

- **価格は検索結果やページで実際に確認できたものだけ書く。** ユーザーはこの数字で売買の判断をするため。
- **URLは検索結果・ページに出てきたものをそのまま書く。** URLを組み立てたり推測したりしない。存在しないページへのリンクは信頼を大きく損なう。
- **同じ商品かを確認する。** 色違い・サイズ違い・互換品・ケースなどの付属品、ジャンク品は除外するか備考に書く。
- **価格は税込の日本円**で書く。送料が分かれば備考に書く。
- 新品と中古は混ぜずに区別する。メルカリなどの「売り切れ」の価格は実際に売れた価格なので、売りたい人にとっては特に重要な相場情報になる。
- メルカリなどはページが動的で中身を取得できないことが多い。検索結果のタイトルや抜粋に価格が出ていればそれを使い、確認できなければ無理に埋めずに検索リンクを案内する。
- 目安として全体で5〜15件。1つのサイトで見つからなくても、他のサイトを調べて先に進む。

### 4. 結果をまとめる

次の形式で日本語で返す。表のURLはMarkdownのリンクにする。

```
## 🔍 特定した商品
| 項目 | 内容 |
|---|---|
| 商品名 | ... |
| ブランド | ... |
| 品番・型番 | ... (写真から読み取り / 検索で特定 / 不明) |
| JANコード | ... |
| 特徴 | ... |
| 確信度 | 高・中・低 (根拠をひとこと) |

## 💴 販売価格 (YYYY年M月D日 時点)
| サイト | 状態 | 価格(税込) | 商品・備考 | URL |
|---|---|---|---|---|
| Amazon | 新品 | ¥12,800 | 商品タイトル / 送料無料 | [リンク](実際のURL) |
| メルカリ | 中古・売り切れ | ¥8,500 | 目立った傷なし | [リンク](実際のURL) |
...
(価格の安い順。新品 → 中古 の順にグループ分けすると読みやすい)

## 📊 相場まとめ
- 新品の最安値: ¥... (サイト名)
- 中古の相場: ¥... 〜 ¥... (売り切れ価格の中央値: 約¥...)
- ひとこと: (買うならどこ、売るならいくらくらいが目安か、など2〜3文)

## 🔗 各サイトで最新価格を見る
- [Amazon](https://www.amazon.co.jp/s?k={検索語})
- [メルカリ (販売中)](https://jp.mercari.com/search?keyword={検索語}&status=on_sale)
- [メルカリ (売り切れ＝相場)](https://jp.mercari.com/search?keyword={検索語}&status=sold_out)
- [楽天市場](https://search.rakuten.co.jp/search/mall/{検索語}/)
- [Yahoo!ショッピング](https://shopping.yahoo.co.jp/search?p={検索語})
- [ラクマ](https://fril.jp/s?query={検索語})
- [PayPayフリマ](https://paypayfleamarket.yahoo.co.jp/search/{検索語})
- [Yahoo!オークション](https://auctions.yahoo.co.jp/search/search?p={検索語})

※ 価格は調査時点のものです。最新の価格・在庫・送料はリンク先でご確認ください。
```

補足:

- 「🔗 各サイトで最新価格を見る」の `{検索語}` は品番(なければ商品名)をURLエンコードして埋める。これは検索ページなので組み立ててよい(個別商品ページのURLは組み立てない)。価格は日々変わるため、このリンクは毎回付ける。
- 価格が1件も確認できなかったサイトは表に入れず、検索リンクだけで案内する。
- 全体で価格がほとんど見つからなかった場合は正直にそう伝え、検索リンクと、より正確に調べるための写真の撮り方(品番タグ・箱・バーコードを写す)を案内する。
- 写真が複数あるときは、すべて同じ商品の別角度とみなして情報を組み合わせる。明らかに別の商品が複数写っている場合は、どれを調べるかユーザーに聞く。
